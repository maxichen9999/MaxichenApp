▶️ So startest du es

cd Lovechat
npm i        # nur beim allerersten Mal — alles landet in Lovechat/node_modules
npm start    # Server auf http://localhost:3900
npm run pair   # WhatsApp-Brücke (eigenes Fenster, QR-Code scannen)
npm test       # alle Tests

🔍 Selbst nachzählen

cd Lovechat
ls server/server.js server/pair.js client/index.html     # müssen alle drei erscheinen
wc -l server/server.js server/pair.js client/index.html
python3 tools/uebersicht.py                              # diese Seite neu erzeugen
