iOS — iPhone & iPad

Krypto-Kern fertig · Chat-Oberfläche fehlt · keine .ipa

In Arbeit

Hier gibt es keine .ipa zum Herunterladen. Nicht, weil ich es vergessen habe — sondern weil eine .ipa auf einem Mac mit Xcode gebaut und mit einem Apple-Developer-Konto (99 €/Jahr) signiert werden muss. Beides habe ich nicht. Eine selbstgebaute „ipa" ohne Signatur würde auf deinem iPhone nicht starten.

Was schon echt ist:

41 Swift-Tests grün 10/10 Anmeldung gegen echten Server ML-KEM-768 byte-identisch zu Android iOS 12+
⬇︎ Swift-Paket ansehen (45 KB) 🍏 .ipa — noch nicht da
Was in dem Paket steckt: Anmelde-Flow, TOTP, Badges, PIN-Sperre, Recovery-Codes und seit V4.15 ML-KEM-768 (FIPS 203, geprüft gegen eine fremde Referenz-Implementierung). Das ist der Post-Quanten-Teil von PQXDH.

Was fehlt: die Chat-Oberfläche, Curve25519 (X3DH), der Doppel-Ratchet und Push. Bis das steht, gibt es kein ehrliches „für iOS verfügbar".

Windows — EXE

Echtes Fenster (WebView2) · lädt die Web-App · 2,4 MB

⚠ Vorab

Die EXE öffnet ein eigenes Fenster — kein Browser-Tab — und lädt darin MaxiChat von maxichen.de. Gleiches Konto, gleiche Chats wie auf dem Handy.

⬇︎ MaxiChat für Windows · 2,4 MB 💬 Ohne Download im Browser
Windows 10 / 11 (x64) 2.450.944 Byte WebView2 nötig (ab Win 10 dabei)
Was ehrlich dazugehört:
  • Das ist kein nativer Windows-Code. Es gibt für MaxiChat keinen — die App ist nativ Android (Compose). Die EXE ist ein Fenster um die Web-App.
  • Sie ist hier nicht auf Windows getestet: In dieser Umgebung läuft kein Windows. Gebaut ist sie als gültiges PE32+-Programm (x64, GUI-Subsystem).
  • Fehlt der WebView2-Runtime (Windows 7/8), sagt sie das und verweist auf die Web-Version.
  • Windows zeigt beim ersten Start „Unbekannter Herausgeber" — die EXE ist nicht signiert (Code-Signing-Zertifikat kostet Geld).

Im Browser nachrechnen

Jeder kann eine Zahl abschreiben. Hier rechnet der Browser die Prüfsumme der Datei selbst aus — über genau die Bytes, die bei dir ankommen.

⏳ Dateien werden geladen …

Rechnet im Browser mit crypto.subtle.digest('SHA-256'). Die Datei wird dafür einmal komplett geladen — das ist der Preis dafür, dass die Prüfung etwas wert ist.
