▶️ In drei Schritten starten

  1. Ein Node-Projekt, ein Befehl: npm i → npm start
    Windows: START-WINDOWS.bat doppelklicken — oder im Terminal in diesem Ordner:
    Mac/Linux: START-MAC-LINUX.command doppelklicken.
    (Erster Start dauert ~1 Minute — die Pakete werden installiert.)
  2. Im schwarzen Fenster erscheint 💗 LoveChat läuft! — Fenster offen lassen.
  3. Browser öffnen: http://localhost:3900
# von Hand im Terminal — im Ordner Lovechat:
npm i                   # nur beim ALLERSTEN Mal (installiert server/node_modules)
npm start               # Server starten

# zweites Fenster, nur wenn du WhatsApp verbinden willst:
npm run pair
npm i gehört in diesen Ordner, nicht in server/ — hier liegt die package.json, und sie installiert die Pakete automatisch eine Ebene tiefer. npm start, npm run pair und npm test funktionieren ebenfalls genau hier.

Warum nicht alles flach in einem Ordner? Weil Server, Oberfläche und Deploy-Ordner getrennt hochgeladen werden müssen — auf dem Webserver landet client/ nach /chat/, nicht der Server-Code. Wären alle Dateien gemischt, würdest du beim Hochladen Passwörter und Datenbank mit veröffentlichen. Die zwei Start-Dateien oben sind der Kompromiss: du siehst und startest alles sofort, der Code bleibt sortiert.
